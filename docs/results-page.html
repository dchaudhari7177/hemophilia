Row E settles it. With the outcome labels randomly shuffled — no signal left to find — training AUC still sits at 1.0000. A model that fits pure noise perfectly is memorising, not learning. Row G then reproduces the published figure almost exactly, by making the one protocol error that produces it.

Over-sampling applied before the split

Random Over-Sampling duplicates minority rows verbatim, then the split is taken. The same patient lands on both sides, and the classifier is graded on rows it has already memorised.

716 of 1,432 test rows (50.0%) are byte-identical copies of training rows → 95.3% accuracy, AUC 0.9938

“Not reported” relabelled as “no inhibitor”

1,744 of 4,040 CHAMP variants have no recorded outcome. Mapping them to zero asserts something the data never says, and pads the majority class so accuracy rises without the model improving.

Prevalence 20.1% → 11.4% · accuracy inflated +7.0 pts · ~502 false negatives injected

Identifier columns fed in as features

HGVS cDNA is a name for the variant, not a property of it. Among the 2,296 labelled rows it has zero duplicates — it is a primary key, and label-encoding it hands the model a lookup table.

4,038 distinct values / 4,050 rows · 0 duplicates among labelled patients
02 — THE REBUILD

Mechanism instead of identity

The HGVS string is discarded; what it means is kept. A parser turns each variant into 135 mechanistic descriptors across seven biological blocks — FVIII domain, distance to each known inhibitor epitope, how much protein a stop codon removes, whether the transcript escapes nonsense-mediated decay, Grantham distance and BLOSUM62 for substitutions, splice offsets, FVIII activity stratum.

The cleanest evidence in the project

Genomic position is real biology, but at nucleotide resolution it is near-unique — the identifier problem in numeric clothing. Snapping positions to a 40-bin grid (~58 residues per bin) costs exactly 0.0000 AUC (0.7372 → 0.7372).

Zero cost means the fine resolution was carrying identity, not signal. A regression test now fails if any engineered feature becomes near-unique again.

What the engineering is actually worth

Measured, not asserted. Variant type and FVIII activity stratum — the two things a clinician already has — reach 0.6985 alone. The full engineered set adds +0.0387 on top of that.

03 — SELECTION

The rule was written before the answer

Two validation protocols disagreed. Repeated cross-validation ranks tree ensembles first. But a random split can place residue 490 in training and residue 491 in test — neighbouring positions in the same epitope, which is interpolation, not prediction. Blocking removes that, and it is the situation a treatment centre is actually in when a newly sequenced patient carries an uncatalogued variant.

Trees lose 3–4× more AUC under blocking than the neural models do. So the tie-break was fixed in advance: among models DeLong cannot separate on repeated CV, ship the highest blocked AUC.

Disclosure

The test set was scored with ExtraTrees before the tie-break had run, and it scored higher. DeepMLP is still what ships. Switching back because the other model scored better on the test set would be selection on the test set — the exact error section 01 documents. Both numbers are stated rather than only the flattering one; the intervals overlap across almost their whole range anyway.

04 — EXTERNAL VALIDATION

It transfers to a different gene

The F8 model is applied unchanged to 351 hemophilia B patients from the CDC CHBMP database — a different gene coding a different protein, with no F9 patient used anywhere in training, feature fitting or threshold selection.

Nothing F8-specific can carry over. What can is the immunology: a null variant abolishes the protein, so the patient was never tolerised to the factor they are later infused with. A model that survived this learned that mechanism. A model that memorised F8 would score chance.

One caveat stated plainly: FVIII coordinates do not map onto the 415-residue factor IX, so the domain, epitope and truncation features are near-constant on this cohort. What transfers is the consequence-class signal — null versus missense, truncating versus in-frame — which is precisely the part that should be gene-agnostic.

The most important caveat in this project

Inside the severe stratum — where essentially every prophylaxis decision is made — AUC falls to 0.694. Inside truncating variants alone it is 0.541, indistinguishable from chance.

Most of the model's apparent discrimination comes from separating null variants from non-null ones — and a clinician already knows that from the variant type, without any model. Within the high-risk group, where a tool would actually change management, this model adds very little.

That is a limit of the data, not of the fitting. Whether a particular severe, null-variant patient develops an inhibitor depends on treatment intensity, product type, age at first exposure and HLA haplotype — none of which CHAMP records. No model recovers from a database what was never in it, and reporting only the pooled 0.727 would have concealed exactly what a reviewer most needs to see.

06 — A SECOND DATASET

The file that appeared to solve it

Section 05 says the binding constraint is missing patient data. A collaborator supplied exactly that — CHAMP with age, ethnicity, treatment regimen, exposure days and family history appended — reporting accuracy in the high eighties.

It was tested rather than adopted. Two things came out.

Where the 89.6% comes from

The file's label counts CHAMP's 1,731 unrecorded outcomes as negatives, moving prevalence from 20.1% to 11.4%. Predicting “no inhibitor” for every patient then scores 88.55%. The trained model scores 89.58% — one point better, while catching 13% of actual cases (16 flagged of 806).

07 — NEGATIVE RESULTS

Four things that did not work

Reported because an experiment that fails is still a measurement, and because a project about honest reporting cannot quietly drop its own disappointments.

  • The custom architecture did not win. A block-attention network built around the seven biological feature groups placed sixth (0.7287), below a plain ExtraTrees. Its value is intrinsic per-patient attribution, not accuracy.
  • Neither ensemble beat a single model. Stacking reached 0.7370, weighted averaging 0.7357, against 0.7412 for ExtraTrees alone.
  • Semi-supervised learning did not help. Self-training over the 1,744 unlabelled rows moved held-out AUC from 0.7504 to 0.7418 — DeLong p = 0.168.
  • Tuning optimism was not there to find. Nested search was set up expecting inflated GridSearchCV scores. The largest gap in either direction was 0.0047 AUC, and three of five models scored higher on the honest outer loop. That particular criticism does not apply to the reference works, and saying so matters — the defects in section 01 are sufficient without adding one the data does not support.

One more, worth its own line: a missingness probe reaches AUC 0.601, meaning the labelled subset is not a random sample of CHAMP. That is informative missingness, and it limits this model's generalisation exactly as much as anyone else's.

08 — WHAT IT IS FOR

A rule-out tool, honestly labelled

Two operating points ship, both fixed on training folds before the test set was touched. A third — the accuracy-maximising one — is reported because review panels ask for accuracy, but it is not what the tool runs on, and the reason is visible in its own row.

Operating pointAccuracy Sens.Spec.Caught / missed
Balanced (Youden's J)64.4% 64.1%64.4%59 / 33

The accuracy-maximising point reaches 83.0% against an 80.0% no-skill baseline — and gets there by declining to predict inhibitors, missing 76 of 92 cases. No threshold anywhere on the curve reaches 85%. That is the arithmetic of a rare outcome, not a property of this model.

The rule-out point is the one worth having: 87.0% sensitivity with 92.2% negative predictive value — a defensible use for a genomic-only model.

Calibration was treated as a first-class requirement rather than an afterthought: isotonic regression moved expected calibration error from 0.272 to 0.043. A risk score used to choose a prophylaxis regimen has to mean what it says.

The next real gain is not a better model. It is patient-level registry data — exposure days, product type, treatment intensity, HLA haplotype. Those are the variables that dominate the outcome, and none of them are in this database.
